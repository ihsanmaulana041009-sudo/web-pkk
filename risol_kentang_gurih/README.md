# Risol & Kentang Gurih — Website

Website single-page untuk brand **Risol & Kentang Gurih**.

## Produk yang ditampilkan
1. **Risol Mayo** — Mulai 3K/pcs
2. **Risol Matcha** — Mulai 3K/pcs
3. **Stik Banana Matcha Lumpia**
4. **Kentang Goreng Renyah Bumbu Tabur** — Rp 5.000/porsi
5. **Bolen Pisang Cokelat** — Rp 10.000/kotak

## Cara membuka
Buka file `index.html` di browser, atau jalankan local server:

```bash
# Python
python3 -m http.server 8080

# lalu buka http://localhost:8080
```
